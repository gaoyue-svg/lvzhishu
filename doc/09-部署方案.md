# 部署方案

## 1. 部署架构

```text
Nginx
↓
Gateway
↓
FastAPI Backend
↓
RAG Service
↓
MySQL / Redis / Milvus / 阿里云 OSS
```

## 2. 服务清单

| 服务 | 说明 |
| --- | --- |
| nginx | 反向代理、静态资源 |
| backend-api | 用户、知识库、后台业务 |
| rag-service | RAG 检索与生成 |
| parser-worker | 文档解析与 OCR |
| embedding-worker | 向量化任务 |
| MySQL | 业务数据库 |
| Redis | 缓存、任务状态、限流 |
| Milvus | 向量数据库 |
| 阿里云 OSS | 文件存储 |
| Neo4j | 法律知识图谱，后续引入 |

## 3. 环境配置

关键环境变量：

```text
APP_ENV
MYSQL_URL
REDIS_URL
OSS_ENDPOINT
MILVUS_HOST
MILVUS_PORT
OPENAI_API_KEY
DEFAULT_CHAT_MODEL
DEFAULT_EMBEDDING_MODEL
JWT_SECRET
```

## 4. 本地开发

建议使用 Docker Compose 启动依赖：

- MySQL
- Redis
- Milvus
- 阿里云 OSS

后端和前端可在本机直接启动，便于调试。

## 5. 生产部署

建议容器化部署：

```text
build image
↓
push registry
↓
run migration
↓
deploy backend
↓
deploy workers
↓
deploy frontend
↓
health check
```

## 6. 文件与索引备份

需要备份：

- MySQL 数据
- 阿里云 OSS 原始文件
- Milvus Collection
- Prompt 版本
- 系统配置

## 7. 可观测性

建议接入：

- OpenTelemetry
- Prometheus
- Grafana
- LangSmith
- 应用日志采集

核心指标：

- API 耗时
- RAG 检索耗时
- LLM 调用耗时
- Token 消耗
- 任务失败率
- Milvus 查询耗时
- 解析任务积压数量
