# 知识库设计

## 1. 知识库类型

| 类型 | 内容 | Collection | 优先级 |
|------|------|-----------|--------|
| law | 法律法规、部门规章、地方性法规、行政法规 | `law` | P0 |
| case | 判例、指导案例、裁判文书、公报案例 | `case` | P1 |
| judicial | 司法解释、会议纪要、指导意见、答复 | `judicial` | P0 |
| contract | 合同模板、企业合同、审查样例、标准条款 | `contract` | P1 |
| enterprise | 企业制度、合规文件、业务规则（租户私有） | `enterprise_{tenant_id}` | P2 |

### 1.1 知识库权限模型

```text
┌─────────────────────────────────────────────────────┐
│                  知识库权限矩阵                       │
├──────────┬────────┬────────┬────────┬───────────────┤

├──────────┼────────┼────────┼────────┼───────────────┤
│ 民法典    │  ✅    │  ✅    │  ✅    │ 公共法律库     │

└──────────┴────────┴────────┴────────┴───────────────┘
```

## 2. 法条结构化解析（Law Structurer）

法律 RAG 的基石能力——将原始法律文本转化为结构化条款树。

### 2.1 条款树模型

```text
法律
 └── 编 (Part)
      └── 章 (Chapter)
           └── 节 (Section)          ← 可选
                └── 条 (Article)     ← 基本检索单元
                     └── 款 (Paragraph)
                          └── 项 (Item)
```

### 2.2 解析流程

```text
原始法律 PDF/Word/TXT
↓
┌─ 文本预处理 ────────────────────────────────────────┐
│ 1. 提取纯文本（OCR → 文本清洗）                       │
│ 2. 去页眉页脚、页码、水印                             │
│ 3. 合并跨页段落                                       │
│ 4. 识别法律标题（如"中华人民共和国民法典"）           │
│ 5. 提取颁布信息（机关、日期、令号）                   │
└──────────────────────────────────────────────────────┘
↓
┌─ 结构识别 ──────────────────────────────────────────┐
│                                                      │
│ 正则模式匹配:                                         │
│   第[一二三四五六七八九十百零]+编 → Part               │
│   第[一二三四五六七八九十百零]+章 → Chapter            │
│   第[一二三四五六七八九十百零]+节 → Section            │
│   第[0-9零一二三四五六七八九十百千]+条 → Article       │
│                                                      │
│ 示例: 民法典                                          │
│   第一编 总则                                         │
│     第一章 基本规定                                   │
│       第一条 为了保护民事主体的合法权益...            │
│       第二条 民法调整平等主体的...                    │
│     第二章 自然人                                     │
│       第一节 民事权利能力和民事行为能力               │
│         第十三条 自然人从出生时起...                  │
│         ...                                          │
│   第二编 物权                                         │
│     ...                                              │
└──────────────────────────────────────────────────────┘
↓
┌─ 法条内容提取 ──────────────────────────────────────┐
│                                                      │
│ 每条法条生成结构化记录:                                │
│ {                                                    │
│   "article_id": "civil_code_0585",                    │
│   "law_name": "中华人民共和国民法典",                  │
│   "article_number": "第五百八十五条",                  │
│   "article_numeric": 585,                             │
│   "path": {                                           │
│     "part": "第三编",                                 │
│     "part_title": "合同",                             │
│     "chapter": "第八章",                              │
│     "chapter_title": "违约责任",                      │
│     "section": null,                                  │
│     "section_title": null                             │
│   },                                                 │
│   "paragraphs": [                                     │
│     {                                                 │
│       "para_index": 1,                                │
│       "text": "当事人可以约定一方违约时应当根据违约情况│
│                向对方支付一定数额的违约金...",          │
│       "is_main_clause": true                          │
│     },                                               │
│     {                                                 │
│       "para_index": 2,                                │
│       "text": "约定的违约金低于造成的损失的...",       │
│       "is_main_clause": false                         │
│     }                                                │
│   ],                                                 │
│   "full_text": "完整的法条原文内容...",                │
│   "internal_references": [                            │
│     { "ref_to": "civil_code_0584", "reason": "损害赔偿" }│
│   ],                                                 │
│   "keywords": ["违约金", "违约责任", "适当减少",       │
│                "迟延履行", "违约金调整"],              │
│   "token_count": 180                                  │
│ }                                                    │
└──────────────────────────────────────────────────────┘
↓
┌─ 法条内部引用识别 ──────────────────────────────────┐
│                                                      │
│ 识别法条文本中对其他法条的引用:                        │
│                                                      │
│ 模式匹配:                                             │
│   "依照本法第X条" → 同法律内部引用                     │
│   "适用《XXX法》第X条" → 跨法律引用                    │
│   "参照...规定" → 软引用                              │
│   "依据前款规定" → 前款引用                           │
│                                                      │
│ 用途: 知识图谱关系构建 + 检索时关联法条展开            │
└──────────────────────────────────────────────────────┘
```

### 2.3 法条版本管理

法律会修订、废止、被取代，RAG 系统必须追踪版本：

```text
┌──────────────────────────────────────────────────────┐
│                  法条版本管理                          │
├──────────────────────────────────────────────────────┤
│                                                      │
│  版本记录结构:                                        │
│  {                                                   │
│    "law_name": "中华人民共和国民法典",                 │
│    "article_number": "第五百八十五条",                 │
│    "versions": [                                      │
│      {                                                │
│        "version_id": "v20210101",                      │
│        "effective_date": "2021-01-01",                 │
│        "status": "现行有效",                            │
│        "text": "当前版本的法条全文...",                  │
│        "amended_by": null,                             │
│        "supersedes": "合同法第114条"                    │
│      },                                               │
│      {                                                │
│        "version_id": "v20210601",  ← 假设未来修订      │
│        "effective_date": "2021-06-01",                 │
│        "status": "草案",                                │
│        "text": "修订后的法条全文(如有)...",              │
│        "amended_by": "立法修正案XX号",                   │
│        "change_summary": "增加了惩罚性赔偿条款"          │
│      }                                                │
│    ]                                                  │
│  }                                                    │
│                                                      │
│  检索时的时间过滤:                                     │
│  - 默认检索 status = "现行有效" 的版本                 │
│  - 用户可选择按特定时间点检索（如"2020年的合同法"）     │
│  - 引用时标注版本号和生效日期                          │
└──────────────────────────────────────────────────────┘
```

### 2.4 版本数据库表设计

```sql
-- 法律基本信息表
CREATE TABLE law_info (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(200) NOT NULL COMMENT '法律全称',
    short_name VARCHAR(100) COMMENT '法律简称',
    promulgation_org VARCHAR(200) COMMENT '颁布机关',
    doc_number VARCHAR(100) COMMENT '文号',
    law_type VARCHAR(50) COMMENT '类型: basic_law/administrative_regulation/judicial_interpretation/local_regulation',
    hierarchy INT COMMENT '效力层级: 1=基本法律 2=行政法规 3=司法解释 4=部门规章 5=地方法规',
    status VARCHAR(20) COMMENT '整体状态: effective/partially_amended/repealed',
    first_effective_date DATE COMMENT '首次生效日期',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 法条表（每条法律中的每个条款）
CREATE TABLE law_article (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    law_id BIGINT NOT NULL COMMENT '所属法律',
    article_number VARCHAR(20) NOT NULL COMMENT '条号，如"第五百八十五条"',
    article_numeric INT NOT NULL COMMENT '数字条号，如585',
    part VARCHAR(100) COMMENT '编',
    part_title VARCHAR(200) COMMENT '编标题',
    chapter VARCHAR(100) COMMENT '章',
    chapter_title VARCHAR(200) COMMENT '章标题',
    section VARCHAR(100) COMMENT '节',
    section_title VARCHAR(200) COMMENT '节标题',
    article_path VARCHAR(500) COMMENT '完整路径: 民法典/合同编/第八章/第585条',
    full_text TEXT NOT NULL COMMENT '法条全文',
    keywords VARCHAR(500) COMMENT '关键词',
    internal_references JSON COMMENT '内部引用关系',
    FOREIGN KEY (law_id) REFERENCES law_info(id),
    INDEX idx_law_article_number (law_id, article_numeric),
    INDEX idx_law_article_path (article_path)
);

-- 法条版本表
CREATE TABLE law_article_version (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    article_id BIGINT NOT NULL COMMENT '关联法条',
    version_number VARCHAR(20) COMMENT '版本号',
    effective_date DATE NOT NULL COMMENT '生效日期',
    expiry_date DATE COMMENT '失效日期',
    status VARCHAR(20) COMMENT '版本状态: effective/amended/repealed/draft',
    text TEXT NOT NULL COMMENT '该版本的条文内容',
    amendment_basis VARCHAR(500) COMMENT '修订依据',
    change_summary TEXT COMMENT '变更摘要',
    supersedes_version_id BIGINT COMMENT '取代的上一版本',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (article_id) REFERENCES law_article(id),
    INDEX idx_version_date (article_id, effective_date),
    INDEX idx_version_status (status)
);
```

## 3. Chunk 策略详解

### 3.1 法律法规 Chunk

双粒度策略：

```text
┌─ 法条级 Chunk (Article-Level) ──────────────────────┐
│                                                      │
│ 切分规则: 一条法条 = 一个 Chunk                       │
│ 适用场景: 法条定位、精确引用、版本管理                 │
│                                                      │
│ Chunk 示例:                                          │
│ {                                                    │
│   "chunk_id": "chk-law-civilcode-0585",               │
│   "chunk_type": "article",                            │
│   "granularity": "article",                           │
│   "text": "当事人可以约定一方违约时应当...",           │
│   "metadata": {                                       │
│     "law_name": "中华人民共和国民法典",                │
│     "article": "第585条",                             │
│     "article_numeric": 585,                           │
│     "chapter": "违约责任",                             │
│     "path": "民法典/合同编/第八章/第585条",            │
│     "version": "20210101",                            │
│     "effective_date": "2021-01-01",                   │
│     "status": "现行有效",                              │
│     "hierarchy": 1,                                   │
│     "keywords": ["违约金", "违约责任", "适当减少"],     │
│     "internal_refs": ["civil_code_0584"],              │
│     "token_count": 180                                │
│   }                                                  │
│ }                                                    │
└──────────────────────────────────────────────────────┘

┌─ 段落级 Chunk (Paragraph-Level) ────────────────────┐
│                                                      │
│ 切分规则: 按段落逻辑切分，500~1000 tokens             │
│ 适用场景: 语义检索、长文理解、背景信息补充             │
│                                                      │
│ Chunk 示例:                                          │
│ {                                                    │
│   "chunk_id": "chk-law-civilcode-0585-p2",            │
│   "chunk_type": "paragraph",                          │
│   "granularity": "paragraph",                         │
│   "text": "约定的违约金低于造成的损失的，人民法院或者  │
│            仲裁机构可以根据当事人的请求予以增加；约定  │
│            的违约金过分高于造成的损失的，人民法院或者  │
│            仲裁机构可以根据当事人的请求予以适当减少。  │
│            当事人就迟延履行约定违约金的，违约方支付    │
│            违约金后，还应当履行债务。",                 │
│   "metadata": {                                       │
│     "law_name": "中华人民共和国民法典",                │
│     "article": "第585条",                             │
│     "article_chunk_id": "chk-law-civilcode-0585",     │
│     "paragraph_index": 2,                             │
│     "context_before": "第一款规定了约定违约金的权利",   │
│     "context_after": "第586条规定了定金",              │
│     "token_count": 120                                │
│   }                                                  │
│ }                                                    │
└──────────────────────────────────────────────────────┘
```

### 3.2 案例 Chunk

案例按审判结构切分，方便检索和引用：

```text
案例全文
├── Chunk 1: 当事人信息 + 诉讼请求
│    Metadata: { chunk_type: "case_basic_info" }
├── Chunk 2: 原告诉称（事实与理由）
│    Metadata: { chunk_type: "plaintiff_claim" }
├── Chunk 3: 被告辩称
│    Metadata: { chunk_type: "defendant_defense" }
├── Chunk 4: 法院查明的事实
│    Metadata: { chunk_type: "court_findings" }
├── Chunk 5: 法院认为（本院认为部分）
│    Metadata: { chunk_type: "court_view" }
├── Chunk 6: 适用法条
│    Metadata: { chunk_type: "applicable_laws" }
├── Chunk 7: 裁判结果
│    Metadata: { chunk_type: "judgment" }
└── Chunk 8: 审判人员 + 日期
     Metadata: { chunk_type: "case_metadata" }
```

### 5.2 典型查询场景

```cypher
-- 1. 法条引用链展开（给定法条，找它引用的法条和解释它的司法解释）
MATCH (a:Article {article_number: "第585条"})-[:REFERENCES]->(ref:Article)
OPTIONAL MATCH (interp:JudicialInterp)-[:INTERPRETS]->(a)
RETURN a, ref, interp

-- 2. 判例引用网分析（某法条在各地法院的适用情况）
MATCH (a:Article {article_number: "第585条"})<-[:APPLIES]-(c:Case)-[:TRIED_BY]->(court:Court)
RETURN court.level AS 法院层级, COUNT(c) AS 引用次数
ORDER BY 引用次数 DESC

-- 3. 相似案例推荐（基于案由 + 适用法条）
MATCH (c1:Case {case_no: "..."})-[:HAS_CAUSE]->(cause:CauseOfAction),
      (c1)-[:APPLIES]->(a:Article),
      (c2:Case)-[:HAS_CAUSE]->(cause),
      (c2)-[:APPLIES]->(a)
WHERE c1 <> c2
RETURN c2, COUNT(a) AS shared_articles
ORDER BY shared_articles DESC LIMIT 5

-- 4. 合同条款合规检查
MATCH (clause:Clause {risk_level: "high"})-[:CONTRADICTS]->(a:Article)
RETURN clause.title, clause.source_contract, a.article_number, a.full_text
```

### 6.2 条款比对引擎

合同审查时，将用户合同条款与模板标准条款比对：

```python
class ClauseComparer:
    """合同条款比对引擎"""

    def compare(self, user_clause: dict, template_clause: dict) -> dict:
        """
        比对一个条款对，返回比对结果

        比对维度：
        1. 条款存在性：user 是否包含 template 中的必备条款
        2. 条款完整性：user 条款是否覆盖 template 条款的所有要点
        3. 条款偏差：关键要素的差异（如违约金比例、管辖方式）
        4. 条款风险：user 条款是否有额外风险
        """
        return {
            "clause_title": user_clause["title"],
            "comparison": {
                "exists": True/False,           # 条款是否存在
                "completeness": 0.0~1.0,        # 完整性得分
                "key_differences": [            # 关键差异
                    {"aspect": "违约金标准", "template": "日万分之五", "user": "日千分之三", "risk": "high"},
                ],
                "missing_elements": ["解除权约定", "验收前置条件"],
                "extra_risks": ["赔偿范围过宽"]
            }
        }
```

### 7.2 版本切换策略

## 8. 数据质量保障

### 8.1 解析质量检查

```text
法条解析完成后自动检查:

1. 结构完整性:
   □ 是否包含法律名称?
   □ 是否提取了所有编/章/节/条?
   □ 条号是否连续（检测是否有遗漏）?
   □ 法条间引用关系是否正确解析?

2. 内容质量:
   □ OCR 识别准确率 > 99%?
   □ 是否存在乱码或截断?
   □ 关键词提取是否合理?

3. 版本信息:
   □ 生效日期是否正确?
   □ 是否有版本标记?
```

### 8.2 Embedding 质量监控

```text
向量化完成后的质量检查:

1. 向量维度: □ 是否为目标维度（如1536）?
2. 异常检测: □ 是否存在全零向量? □ 是否存在极值?
3. 语义质量: □ 相似法条的向量是否接近?
             □ 不同法律的向量是否区分?
```
