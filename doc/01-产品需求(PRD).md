# LegalMind AI 产品需求文档（PRD）

## 1. 项目定位

LegalMind AI 是一个企业级法律智能知识平台，不只是单纯的法律 RAG 问答系统。平台面向企业法务、律师、合规人员和业务团队，提供法律知识库管理、法规与案例检索、合同审查、法律咨询、文书生成、检索实验和后台配置能力。

目标工程规模按商业项目规划：

- 核心模块：18~22 个
- API 接口：120~180 个
- 数据库表：60~80 张，包含业务表、日志表、配置表和审计表
- 代码规模：约 4~6 万行 Python + Vue

## 2. 核心用户

| 用户角色 | 主要诉求 |
| --- | --- |
| 企业法务 | 快速查询法规、分析合同风险、沉淀企业法律知识 |
| 律师 | 检索案例、生成法律意见、整理文书材料 |
| 合规人员 | 检查制度和合同是否符合法规要求 |
| 管理员 | 管理知识库、模型、Prompt、权限、日志和系统配置 |

## 3. 业务流程

```text
用户
↓
创建知识库
↓
上传法律法规、案例、合同、制度文件
↓
系统解析与 OCR
↓
Chunk 切分
↓
Embedding
↓
Milvus / BM25 / 知识图谱
↓
Agent 推理
↓
生成带引用的法律回答或报告
```

## 7. Agent 模块

| Agent | 功能 |
| --- | --- |
| 法律咨询 Agent | 面向一般法律问题，返回法规依据和建议 |
| 案例分析 Agent | 检索相似案例，提取裁判观点 |
| 合同审查 Agent | 识别合同风险、输出风险等级和修改建议 |
| 法条定位 Agent | 根据问题定位法律、章节、条款和版本 |
| 文书生成 Agent | 生成律师函、法律意见书、合同补充条款等 |

## 9. 商业功能

### 9.1 Workflow 工作流

支持非聊天式业务流程编排，例如合同审查：

```text
开始
↓
上传合同
↓
OCR
↓
合同条款 Chunk
↓
风险分析
↓
生成审查报告
↓
导出 PDF
```


### 9.3 Retrieval Lab 检索实验室

用于观察和调优检索链路：

```text
Query Rewrite
↓
Milvus Top20
↓
BM25 Top20
↓
Merge
↓
Rerank
↓
Context
↓
LLM Answer
```

## 10. 非功能需求

- 支持多租户数据隔离
- 关键操作可审计
- 检索和回答过程可追踪
- 法律引用必须可回溯
- 大文件解析异步执行
- 支持模型供应商切换
- 支持向量索引增量更新
- 支持后台配置 Prompt 和 Agent
