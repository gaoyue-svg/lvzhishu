# 任务：搭建 LawRAG 后端骨架（FastAPI）

## 项目背景

LawRAG 是一个法律 RAG 智能平台。已完成全套设计文档（`doc/` 目录）、数据库设计（`sql/init.sql`）。现在需要搭建 FastAPI 后端基础骨架，对应项目路线图**阶段一：基础工程**。

## 技术要求

- Python >= 3.12
- FastAPI（异步）
- SQLAlchemy 2.0 async + aiomysql
- Redis async（redis-py）
- JWT 鉴权（pyjwt + bcrypt）
- uvicorn
- 依赖管理用 uv（pyproject.toml）

### 3. config.py

- 用 `pydantic-settings` 的 `BaseSettings`，自动从 `.env` 加载
- 包含所有环境变量的类型定义和默认值
- 提供一个全局 `settings` 单例

### 4. database.py

- MySQL：用 `create_async_engine` + `async_sessionmaker`，连接池参数从 config 读取
- 提供一个 `async def get_db()` 生成器，用于 FastAPI 依赖注入
- Redis：用 `redis.asyncio.Redis.from_url()` 创建连接池
- 提供一个 `async def get_redis()` 生成器
- 在应用启动时（lifespan），自动执行 `sql/init.sql`（仅当数据库中无表时），确保开发环境一键启动

### 5. middleware/trace_id.py

- 每个请求生成一个 UUID 作为 trace_id
- 注入到：
  - `request.state.trace_id`
  - 响应头 `X-Trace-Id`
  - 日志上下文（通过 logging filter 或 contextvars）
- 返回一个 FastAPI Middleware 类或 `@app.middleware("http")` 函数

### 6. middleware/exception.py

- 全局异常捕获，分类处理：
  - `HTTPException` → 取其 status_code 和 detail
  - `ValidationError`（Pydantic）→ 422，返回字段级错误
  - 未知异常 → 500，返回 `{"code": 500, "message": "Internal server error"}`，**不暴露堆栈**
- 开发环境（`APP_DEBUG=true`）可以在 message 中包含异常类型名

### 7. schemas/response.py

统一响应模型，**所有接口**都用这个格式：

```python
class ApiResponse(BaseModel, Generic[T]):
    code: int = 0
    message: str = "success"
    data: T | None = None

class PaginatedResponse(BaseModel, Generic[T]):
    code: int = 0
    message: str = "success"
    data: list[T] = []
    total: int
    page: int
    page_size: int
```

### 8. schemas/auth.py

```python
class RegisterRequest(BaseModel):
    username: str = Field(min_length=2, max_length=50)
    email: str = Field(pattern=r"...")  # 基本邮箱正则
    password: str = Field(min_length=6, max_length=100)

class LoginRequest(BaseModel):
    username: str   # 可以是 username 或 email
    password: str

class TokenResponse(BaseModel):
    access_token: str
    refresh_token: str
    token_type: str = "bearer"
    expires_in: int

class UserProfileResponse(BaseModel):
    id: int
    username: str
    email: str
    phone: str | None
    avatar: str | None
    role: str
    status: str
    created_at: datetime
```

### 9. models/*.py

用 SQLAlchemy 2.0 Mapped 风格（非 Declarative Base 旧式写法），严格对应 `sql/init.sql` 中的字段：

- 表名、字段名、类型、注释与 init.sql 完全一致
- 每个 ORM 类加 `__tablename__` 和完整的 `comment` 参数
- 不用定义外键关系（`relationship`），只定义 Column（等后续需要 JOIN 时再加）
- `created_at` 和 `updated_at` 用 `server_default` 映射 SQL 的 `CURRENT_TIMESTAMP`

示例风格：

```python
from sqlalchemy.orm import Mapped, mapped_column
from sqlalchemy import String, BigInteger, DateTime, Text, func

class User(Base):
    __tablename__ = "user"
    id: Mapped[int] = mapped_column(BigInteger, primary_key=True, autoincrement=True)
    username: Mapped[str] = mapped_column(String(50), unique=True, nullable=False)
    ...
```

### 10. services/auth.py

函数清单：

| 函数 | 说明 |
|------|------|
| `hash_password(password: str) -> str` | bcrypt |
| `verify_password(password: str, hashed: str) -> bool` | bcrypt |
| `create_access_token(user_id: int) -> str` | JWT，payload 含 `sub`、`exp`、`type="access"` |
| `create_refresh_token(user_id: int) -> str` | JWT，payload 含 `sub`、`exp`、`type="refresh"` |
| `decode_token(token: str) -> dict` | 解码 JWT，验证过期，返回 payload |
| `get_current_user(token: str, db: AsyncSession) -> User` | 从 token 解出 user_id，查数据库返回 User。token 从 `Authorization: Bearer <token>` 头中获取。写成一个 FastAPI Depends |

### 11. routers/auth.py

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/register` | 注册：检查用户名/邮箱唯一性 → 密码哈希 → 插入 user 表 → 返回 TokenResponse |
| POST | `/api/auth/login` | 登录：查用户（username 或 email） → 验证密码 → 生成双 token → 更新 last_login_at → 返回 TokenResponse |
| POST | `/api/auth/logout` | 退出：将 token 加入 Redis 黑名单（key: `blacklist:{token}`，TTL 与 token 过期时间一致） |

要求：
- 所有返回值用 `ApiResponse` 包裹
- 密码错误不提示"密码错误"，统一提示"用户名或密码错误"
- 注册时邮箱格式校验

### 12. routers/user.py

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/user/profile` | 获取当前用户信息（需鉴权） |
| PUT | `/api/user/profile` | 修改用户信息：username / email / phone（需鉴权） |
| PUT | `/api/user/password` | 修改密码：需旧密码验证 → 新密码哈希 → 更新（需鉴权） |

### 13. main.py

- 用 `lifespan` 管理启动/关闭（启动时连接数据库、初始化表、连接 Redis）
- 注册中间件：trace_id → CORS → exception handler
- 自动收集 `routers/` 下的所有 router 并 `include_router`
- 注册一个 `GET /api/health` 返回 `{"status": "ok", "version": "0.1.0"}`
- CORS：开发环境允许所有来源，生产环境可配置
- Swagger 文档：`/docs` 和 `/redoc` 保留

### 14. utils/logger.py

- 用 Python 标准 `logging` 即可，配置 JSON 格式或带颜色的终端格式
- 使用 `contextvars` 传递 trace_id，每条日志自动带上 trace_id
- 提供 `get_logger(__name__)` 工具函数

## 质量标准

- 所有函数有 docstring
- 所有接口在 `/docs` 中有完整的 OpenAPI 描述（用 FastAPI 的 `summary`、`description` 参数）
- 密码绝不打印到日志
- ORM 用 async session，不出现同步阻塞
- Redis 操作要处理连接失败的情况，不阻塞请求
- `pyproject.toml` 中的依赖版本写到 minor 版本即可

## 验证方式

生成代码后，后端应能做到：

```bash
# 1. 安装依赖
uv sync

# 2. 启动（前提：MySQL 和 Redis 已运行）
uv run uvicorn backend.main:app --reload --port 8000

# 3. 访问 http://localhost:8000/docs 看到 Swagger

# 4. 注册用户
curl -X POST http://localhost:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"test","email":"test@example.com","password":"123456"}'

# 5. 登录
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"test","password":"123456"}'

# 6. 获取用户信息
curl http://localhost:8000/api/user/profile \
  -H "Authorization: Bearer <access_token>"
```
