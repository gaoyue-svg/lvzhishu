# 项目路线图

## 1. 阶段一：基础工程

目标：搭建可运行的前后端基础框架。

- FastAPI 项目结构
- Vue 管理端结构
- MySQL 接入
- Redis 接入
- 用户登录
- 统一响应
- 统一异常
- 日志与 trace_id

交付物：

- 可启动的后端服务
- 可启动的前端页面
- 用户登录和 Dashboard 雏形

## 2. 阶段二：知识库与文档入库

目标：完成法律知识入库链路。

- 知识库 CRUD
- 文件上传
- 阿里云 OSS 存储
- PDF / Word 解析
- OCR 预留
- Chunk 切分
- Metadata 抽取
- 解析任务状态

交付物：

- 可上传文档
- 可查看解析状态
- 可查看 Chunk

## 3. 阶段三：Embedding 与检索

目标：完成基本 RAG 检索。

- Embedding 模型接入
- Milvus Collection 初始化
- 向量写入
- BM25 检索
- Hybrid Retriever
- Rerank
- 检索 Trace

交付物：

- 可通过问题检索相关 Chunk
- Retrieval Lab 初版

## 4. 阶段四：AI 问答

目标：完成带引用的法律问答。

- Chat API
- 流式输出
- 会话历史
- Query Rewrite
- Query Expand
- Context Compression
- Citation
- Citation Validator

交付物：

- 可进行多轮法律问答
- 回答带可追溯引用

## 5. 阶段五：Agent 能力

目标：上线核心法律 Agent。

- LangGraph 编排
- 法律咨询 Agent
- 案例分析 Agent
- 合同审查 Agent
- 法条定位 Agent
- 文书生成 Agent

交付物：

- 多个业务 Agent 可用
- 合同审查可生成风险报告

## 6. 阶段六：后台商业化能力

目标：补齐商业项目后台配置能力。

- Prompt 管理
- Prompt 版本与回滚
- 模型管理
- Agent Builder
- Workflow 管理
- 日志中心
- 系统配置

交付物：

- 管理员可配置 Prompt、模型和 Agent
- 支持工作流式合同审查

## 7. 阶段七：高级能力

目标：拉开与普通法律 RAG 项目的差距。

- 法律知识图谱
- GraphRAG
- 法规自动更新
- 增量索引
- 检索评估集
- RAGAS / LangSmith
- OpenTelemetry
- MCP 工具调用
- 多模态法律分析

交付物：

- 可评估、可观测、可迭代的企业级法律智能平台

## 8. 推荐里程碑

| 里程碑 | 内容 |
| --- | --- |
| M1 | 用户、知识库、文档上传 |
| M2 | Chunk、Embedding、Milvus |
| M3 | Hybrid RAG、带引用问答 |
| M4 | 合同审查、案例分析、文书生成 |
| M5 | Prompt、模型、Agent 后台配置 |
| M6 | Workflow、Retrieval Lab、评估体系 |
| M7 | 知识图谱、自动更新、多模态 |
