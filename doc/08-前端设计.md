# 前端设计

## 1. 技术栈

- Vue 3
- TypeScript
- Vite
- Pinia
- Vue Router
- Element Plus 或 Naive UI
- Axios
- ECharts

## 2. 页面结构

```text
登录页
↓
主布局
├── Dashboard
├── 知识库
├── 文档
├── Chunk
├── 聊天
├── Agent
├── Workflow
├── Retrieval Lab
├── Prompt
├── 模型管理
├── 日志
└── 系统配置
```

## 3. Dashboard

展示关键指标：

- 知识库数量
- 文档数量
- Chunk 数量
- Embedding 数量
- Milvus 容量
- 今日 Query
- 平均耗时
- 失败任务数
- 模型调用成本

## 4. 知识库页面

功能：

- 创建知识库
- 编辑知识库
- 删除知识库
- 查看知识库状态
- 进入文档列表
- 设置访问权限

## 5. 文档页面

功能：

- 上传文件
- 查看解析状态
- 查看 Embedding 状态
- 重新解析
- 重新向量化
- 删除文件
- 查看错误日志

## 6. Chunk 页面

功能：

- 按知识库、文档、关键词筛选
- 查看 Chunk 原文
- 查看 Metadata
- 修改 Chunk
- 重建单个 Chunk 向量
- 查看引用次数

## 7. 聊天页面

功能：

- 会话列表
- 多轮问答
- 流式输出
- 引用来源展开
- 上传附件
- 重新生成
- 评价回答
- 导出记录

## 8. Retrieval Lab

用于研发和管理员调试：

- 输入 Query
- 展示 Rewrite 结果
- 展示 Milvus TopK
- 展示 BM25 TopK
- 展示 Merge 结果
- 展示 Rerank 分数
- 展示最终 Context
- 展示 LLM 回答

## 9. Prompt 管理

功能：

- Prompt 列表
- 新建 Prompt
- 编辑 Prompt
- 版本记录
- 发布版本
- 回滚版本
- 测试 Prompt

## 10. Agent Builder

功能：

- 新建 Agent
- 选择模型
- 配置 Prompt
- 绑定知识库
- 选择 Tools
- 配置 Memory
- 调试 Agent
- 发布 Agent

## 11. 交互原则

- 后台页面以高密度信息展示为主
- 状态、进度、错误信息必须清晰可见
- 长任务使用进度条和任务日志
- 检索与生成过程支持 Trace 展开
- 表格支持筛选、分页、排序
- 风险报告支持导出 PDF
